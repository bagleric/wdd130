Installing Git

  1. Download Git from git-scm.com/downloads
  2. Run the installer and follow the setup wizard
  3. Accept the default settings (recommended for beginners)
  4. Verify installation by opening a terminal and typing: git --version

Adding This Repo to GitHub

  1. Create a new repository on GitHub.com
  2. Open a terminal in your project folder
  3. Initialize Git: git init
  4. Add your files: git add .
  5. Commit your changes: git commit -m "Initial commit"
  6. Link to GitHub: git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
  7. Push to GitHub: git branch -M main then git push -u origin main

Common Issues & Solutions

1. "Git is not recognized as a command"

Problem: After installing Git, the terminal doesn't recognize git commands.

Solution: Restart your terminal/computer after installation. If the issue persists, manually add Git to your PATH environment variable (usually C:\Program Files\Git\cmd on Windows).

2. Authentication Failed / Permission Denied

Problem: Unable to push to GitHub with username and password.

Solution: GitHub no longer accepts passwords for authentication. You need to use a Personal Access Token (PAT):

  • Go to GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
  • Generate a new token with 'repo' permissions
  • Use the token as your password when prompted
  • Better yet, set up SSH keys for permanent authentication

3. "Fatal: remote origin already exists"

Problem: Trying to add a remote that's already configured.

Solution: Either remove the existing remote first with git remote remove origin, or update it with git remote set-url origin YOUR-NEW-URL

4. Merge Conflicts

Problem: Git can't automatically merge changes when pulling or merging branches.

Solution:

  • Open the conflicted files (marked with <<<<<, =======, and >>>>>>)
  • Manually edit to keep the desired changes
  • Remove the conflict markers
  • Run git add . then git commit -m "Resolved merge conflict"

5. "Nothing added to commit"

Problem: Trying to commit but forgot to stage files.

Solution: Use git add . to stage all changes, or git add filename for specific files, before running git commit

6. Accidentally Committed to Wrong Branch

Problem: Made commits on the main branch instead of a feature branch.

Solution:

  • Create a new branch: git branch feature-branch
  • Reset main branch: git reset HEAD~1 --hard (use carefully!)
  • Switch to your feature branch: git checkout feature-branch

7. "Updates were rejected"

Problem: Can't push because remote has changes you don't have locally.

Solution: Pull the changes first with git pull origin main, resolve any conflicts, then push again with git push origin main

Problem: Git asks for user.email and user.name.

Solution: Set your identity globally:

  • git config --global user.name "Your Name"
  • git config --global user.email "your.email@example.com"
